To navigate through this application on Visual Studio, 
click the run button at the top that is indicated by a green triangle with https to the right of it. 
This with then run the Smart-X hydroponic farming application and automatically navigate the user to the home page. 
Once on the home page the user will see the title, its description and the available or soon to be implemented features. 
The user can either navigate to the available pages by clicking on the available cards or use the items on the right of the navigation bar.
The user can then register their hydroponic sensors and add the relevant telemetry data to the sensors. 
Files may also be attached to the sensors. 
All the created sensors are then shown with their respective details. 
If there are any errors, they will be caught and an error message will be provided alerting the user as to what went wrong.
